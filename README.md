# QNTip
Tor ağı üzerinden otomatik IP rotasyonu yapan, yerel HTTP/SOCKS5 proxy sunan, şifreli ve şifresiz iki modda çalışabilen, Windows için geliştirilmiş gelişmiş bir gizlilik aracıdır. Firefox gibi tarayıcıları tek tıkla Tor üzerinden çıkarır, belirlediğiniz aralıklarla IP adresinizi otomatik değiştirir ve her şeyi canlı terminal paneli ile gösterir.
